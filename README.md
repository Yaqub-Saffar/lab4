# 电子公文交换系统（《密码系统设计》实验四 · 密码模块的应用）

> 20241422 穆弈涵　B/S 架构　Python 3.12 + Flask + SQLite + 国密（SM2/SM3/SM4）

## 一、这个系统做了什么

一个带商用密码保护的电子公文交换系统：科员起草公文，科长审核，发送时用国密算法加密并签名，
收方验签后解密查看、签收、处理；全过程留审计日志；管理员按"三员分离"划分职责。

## 二、运行方法

```powershell
# 1. 安装依赖
py -m pip install -r requirements.txt

# 2. 初始化数据库（会创建 data.db 并写入演示账号）
py db.py

# 3. 启动
py app.py
# 浏览器打开 http://127.0.0.1:8000
```

## 三、安全设计（对应作业要求）

| 要求 | 实现 |
|---|---|
| 身份鉴别（口令不存明文） | 16 字节随机盐 + SM3 迭代 1000 次，库里只有 `pwd_salt` 与 `pwd_hash` |
| 访问控制 | 角色→权限矩阵落库，路由级 `@require_perm` 校验，越权记审计 |
| 三员分离 | 系统管理员 / 安全保密管理员 / 安全审计员 三权分立且互斥，业务岗不得兼任 |
| 安全审计 | 所有关键操作写 `audit_log`，触发器禁止 UPDATE/DELETE，审计员只读 |
| 正文机密性 | 每篇随机 16 字节 DEK，SM4-CBC 加密，IV 随机 |
| 密钥分发 | DEK 用接收方 SM2 公钥加密，形成数字信封 |
| 完整性/抗抵赖 | SM3 摘要 + SM2 签名（发送方私钥），收方验签后才可签收 |
| 私钥保护 | 私钥用口令派生的 KEK 做 SM4 加密后存库，明文私钥只在内存 |
